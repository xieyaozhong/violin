# 弦之境 · Violin Atlas

繁體中文小提琴學習中心，原網站位於 https://xieyaozhong.github.io/violin/ 。純靜態 HTML/CSS/JavaScript，不需要 API 金鑰或付費後端。轉換器會按需下載 Basic Pitch、OpenSheetMusicDisplay、fflate 與公開音色採樣。

## 內容

- 篠崎弘嗣經典少年系列與新版1–4冊、鈴木及其他系統教材
- Wohlfahrt、Kayser、Ševčík、Schradieck、Kreutzer、Paganini 等練習曲和公有領域作品的合法來源
- Wikimedia Commons 逐檔授權的真實演奏錄音，可播放、調速、循環、查看授權及前往原始來源
- 自編樂理、演奏技巧、聲學、音色文章和雙語術語
- 指板音高實驗、大小調音階、音程耳訓、節拍器、練習紀錄
- 本機收藏、進度及紀錄匯出，不需註冊

## 開發與部署

直接開啟 index.html 可使用大部分功能；音訊由 Wikimedia Commons 的原始檔案服務提供，需網路連線。以本機靜態伺服器啟動可獲得一致的瀏覽器環境，例如 `python -m http.server 8000`。

GitHub Pages 設定：main 分支、根目錄 `/`。若尚未啟用 Pages，需在 Settings → Pages 選擇 Deploy from a branch，再選 main / (root)。無需建置或安裝依賴。

- `data.js`：書目、錄音、原創學習文章、術語、路徑、來源
- `app.js`：路由、互動、播放器、音高實驗與紀錄
- `styles.css`：響應式版面與配色
- `index.html`：語意化頁面結構

## 轉換器 2.0

- 音訊、格式 0/1 MIDI、partwise/timewise MusicXML、MXL、弦之境 JSON 專案匯入。失敗時保留現有作品；鼓軌不轉為小提琴旋律。
- 選擇音訊分析起點和長度，於 Worker 內進行 Basic Pitch 辨識。停止分析會終止 Worker；完成後也會釋放模型。
- 保留原始辨識音符，調整移調、音域或量化後可直接重新編曲。相同辨識參數會重用音符結果。
- 空白樂譜、作品名稱、音符時間軸、音符增刪修改、30 步復原／重做。非輸入欄位中可用 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl+Y。
- 真實樂器採樣、變速、音量、揉弦、殘響、整首循環。WAV 套用試聽的音色、速度、音量與效果；MIDI/MusicXML 保留樂譜的速度，不套用試聽倍率。
- 自動草稿儲存原始與編輯後音符、已套用樂譜設定及待套用控制值。重新開啟可載入；舊版草稿會中和移調，避免累加。
- JSON 專案可跨瀏覽器備份。**不包含原始音訊**，需要重新辨識時請另行匯入音訊。匯入不同檔案或建立新作品後，再次儲存會替換目前瀏覽器草稿；重要作品請先下載專案。
- 五線譜排版失敗時保留音符並提供錯誤提示，不把替代示意圖當正式譜列印。

### 使用與開發

轉換器使用 JavaScript 模組與 Worker，請使用 HTTP(S)，不要直接雙擊 converter.html。安裝 Node.js 20 以上後，在專案資料夾執行 `npm start`，開啟顯示的本機網址。預設為 http://127.0.0.1:8173/converter.html 。

開發測試：`npm ci` 後執行 `npm test`。測試包含 MIDI/XML 往返、多軌、變速、播放取消、草稿與操作流程；DOM 與 Web Audio 使用測試替身，並非真實瀏覽器或實際聆聽測試。

發布：`npm run build` 將可發布檔案複製到 dist。GitHub Pages 可使用 dist 中的靜態檔案，或保持原有 main 分支根目錄發布方式（需包括 project.js、transcribe-worker.js）。

### 範圍與限制

最多 20,000 個音符、2 小時音符時間範圍；MusicXML 最多 1,024 小節、16 個同時聲部；WAV 依試聽速度計算，最多 10 分鐘（另保留效果尾音）。音訊檔上限 250 MB；樂譜／專案上限 20 MB；MXL 解壓上限 40 MB。

MusicXML 匯入保留基本音高、節奏、連結線、多聲部、拍號與速度變更；不是完整記譜軟體。反覆記號不展開，裝飾音、微分音、弓法與部分表情記號不完整保留。重新匯出會依選定拍號、調號與單一 BPM 重新記譜；實際秒數保留於音符資料。複雜混音的辨識結果仍需人工校對。標示「雙聲部」僅代表最多兩個音，不保證所有雙音都能在相鄰琴弦上演奏。

首次使用需要網路取得模型、採樣與樂譜函式庫。網路失敗時可繼續編輯、下載 MIDI 或備份專案；不會上傳原始音訊。清除網站資料、無痕模式結束或換裝置，可能失去瀏覽器草稿。
